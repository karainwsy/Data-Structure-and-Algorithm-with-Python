# Data Structure and Algorithm with Python

This repository records my learning journey through **data structures and algorithms**, with Python as the primary implementation language.

The goal is not simply to read and memorize algorithms, but to develop the ability to **understand, implement, test, debug, and analyze** them independently.

## Learning Approach

For each topic, I try to follow this process:

```text
Understand the concept
        ↓
Design the solution
        ↓
Implement it myself
        ↓
Test and debug
        ↓
Analyze complexity
        ↓
Summarize what I learned
```

AI tools may be used as learning assistants, but the core implementations are written and understood by myself.
